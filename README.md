# Interview Preparation

A simple productivity dashboard made using HTML, CSS, and JavaScript.  
It helps users manage tasks, track DSA progress, use a Pomodoro timer, and monitor productivity.

# Features

- Task Manager
- Pomodoro Timer
- DSA Tracker
- Productivity Progress
- LocalStorage Support

# Technologies Used

- HTML
- CSS
- JavaScript
- Vercel

# Deployment

This project is deployed using Vercel.

# PURPOSE
Built for practicing frontend development concepts like DOM manipulation, local storage, event handling, and responsive UI design.
